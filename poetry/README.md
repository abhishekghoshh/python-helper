# Poetry Helper

## Useful comands

```zsh
#
poetry env use python3.10

#
eval $(poetry env activate)

#
poetry new <app-name>

#
poetry add <package-name>

#
poetry add <group> <package-name>

# 
poetry env info

#
poetry env list

#
poetry env remove <poetry-project-name>

# 
poetry lock
poetry lock -vvv

#
poetry install

#
poetry shell
```
